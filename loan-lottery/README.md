# قرعه‌کشی وام خانگی

وب‌اپ Next.js برای مدیریت صندوق وام خانگی/فامیلی و انجام قرعه‌کشی ماهانه.

## امکانات
- ثبت اعضا با تعداد سهم؛ به هر سهم یک شماره قرعه ثابت داده می‌شود
- گردونه شانس: شماره‌ها روی گردونه می‌چرخند و با توقف، شماره و نام برنده نمایش داده می‌شود
- ثبت پرداخت قسط ماهانه هر عضو
- انتخاب برنده با `crypto.getRandomValues` (گردونه فقط نتیجه را نمایش می‌دهد)
- برندگان قبلی تا پایان دوره از قرعه‌کشی حذف می‌شوند
- سوابق با تاریخ شمسی و امکان لغو آخرین قرعه‌کشی
- پشتیبان‌گیری و بازیابی با فایل JSON
- راست‌چین، اعداد فارسی، حالت تاریک

اطلاعات در `localStorage` مرورگر ذخیره می‌شود و سرور یا دیتابیس لازم نیست.

## اجرا
```bash
npm install
npm run dev     # http://localhost:3000
npm test        # تست منطق قرعه‌کشی
npm run build
```
