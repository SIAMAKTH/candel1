# بلیط شانس

سایت قرعه‌کشی با خرید بلیط شانس، ساخته‌شده با Next.js.

## صفحه‌ها
- **خانه**: معرفی سایت، قرعه‌کشی ویژه با شمارش معکوس، قرعه‌کشی‌های فعال و آخرین برندگان
- **قرعه‌کشی‌ها** و **صفحه هر قرعه‌کشی**: خرید بلیط با نام و موبایل، دریافت شماره بلیط اختصاصی
  (از ۱۰۰۱)، فهرست بلیط‌های فروخته‌شده و گردونه شانس برای انجام قرعه‌کشی
- **برندگان**: شماره بلیط و نام برنده هر قرعه‌کشی
- **بلیط‌های من**: جستجوی بلیط‌ها و وضعیت برد با شماره موبایل
- **مدیریت**: ساخت و حذف قرعه‌کشی، گزارش فروش، پشتیبان‌گیری

برنده با `crypto.getRandomValues` از بین همه بلیط‌ها انتخاب می‌شود و گردونه فقط نتیجه را نمایش
می‌دهد (اگر بلیط‌ها زیاد باشند، نمونه‌ای از شماره‌ها به همراه شماره برنده روی گردونه می‌آید).

## محدودیت‌های فعلی
- اطلاعات در `localStorage` مرورگر ذخیره می‌شود؛ برای سایت واقعی چندکاربره، سرور و دیتابیس لازم است.
- درگاه پرداخت وصل نیست و بلیط بدون پرداخت واقعی ثبت می‌شود.
- صفحه مدیریت رمز عبور ندارد.

## اجرا
```bash
npm install
npm run dev     # http://localhost:3000
npm test        # تست منطق خرید بلیط و قرعه‌کشی
npm run build
```
